## Dependency notes

- **001 is sequenced first** because it creates the `tests/` harness
  (`conftest.py`, `pyproject.toml`, `pytest`) that 002/003/004 all add regression
  tests to. Each later plan can bootstrap the harness itself if 001 hasn't run,
  but running 001 first is cleaner and zero-risk (it only *adds* tests).
- **002 is the most urgent fix by priority** (the documented production autostart
  path crash-loops today). Its *code change* is independent; only its regression
  test needs 001's harness. If you must ship 002 before 001, do its code fix +
  static `grep`/`ast` checks, then add the test once 001 lands.
- 003 and 004 are independent of each other; either order is fine after 001.
